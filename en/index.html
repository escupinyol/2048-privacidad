Summary

This application does not collect, send or share any personal data. It contains no advertising and no analytics components (no third-party SDKs).

Data that is stored

The application stores the following on the device itself, using the system's local storage:

  • Your records, one for each board size.
  • The state of the game in progress.
  • Your settings: board size, sound, music, chosen song and light or dark mode.

That data never leaves the phone. The application does not request internet access permission, so it cannot transmit any information.

Minors

Because no data is collected, the application is suitable for all ages under Google Play's criteria.

Deleting data

Simply uninstall the application: all data it generated is removed.

Contact

For any question about this policy, contact the developer through the application's listing on Google Play.

This policy is provided in line with Google Play requirements for applications with zero data collection.
